# Ralph Loop Progress & Codebase Patterns Ledger

## Codebase Patterns
- **Hardware Integration & BLE Services**: Peripheral listeners like `SmartAirbagBridgeService` and `BleRemoteService` implement stateful notifiers (`ValueNotifier<AirbagConnectionState>`, `ValueNotifier<AirbagTelemetry>`) and hook directly into `SafetyService.instance.externalImpact(...)` to avoid intermediary UI bottlenecks and guarantee sub-150ms execution.
- **Dead Reckoning Fusion**: `DeadReckoningEngine` acts as an autonomous sensor fusion layer inside `ConvoyService`. It intercepts track point creation when GPS accuracy drops >50m or fix age exceeds 3s, projects along polyline segments, and smoothly interpolates positions back to native fixes over a 4-second convergence window upon tunnel exit.
- **Defense-in-Depth Emergency Fallback**: Emergency dispatch adheres to the hierarchy: Native Cellular / WebSockets -> Server Emergency Gateway (Twilio/Infobip/WhatsApp) -> Local P2P Mesh -> 112 ERSS Dialer / Satellite SOS.
- **Glove-Friendly Touch Guidelines**: All cockpit actionable targets strictly enforce `BoxConstraints(minWidth: 48, minHeight: 48)` or larger (SOS button uses `minWidth: 56, minHeight: 56` with hold gesture) to ensure effortless operation with thick riding gloves in extreme weather.
- **Zero Mocks in Production Runtime**: All mock adapters are strictly confined to test fixtures under `test/` or default to concrete production implementations when initialized without arguments in production code.
- **Convoy Multi-Rider Orchestration**:
  - Sub-cluster split detection calculates along-route distances between forward pack and trailing cluster, automatically tagging `CONVOY_SPLIT` to suppress `SEPARATED` alarm spam during toll booths or railway crossings.
  - Dynamic Rendezvous markers calculate convergence vectors and auto-resolve split state when all riders arrive within a $150\text{ m}$ radius.
  - Sweeper monitoring runs an asynchronous watchdog detecting halted sweeper nodes ($0\text{ km/h}$ or offline $>60\text{ s}$) while the forward pack moves, triggering high-priority reverse escalation to the Lead.
  - Concurrent multi-incident handling isolates state per `alertId`, ensuring responder assignments, medical data, and resolution events never collide.
