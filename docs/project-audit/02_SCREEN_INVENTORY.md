## 4. Cockpit Shell Deep-Dive: `RiderHomeScreen` & `LiveCockpitMapScreen`

### 1. `RiderHomeScreen` Architectural Breakdown
* **Role**: Primary persistent application shell (`Scaffold`) hosting the persistent 4-destination `NavigationBar` and `IndexedStack`.
* **State & Tab Structure**:
  * `HomeTab.ride` (Tab 0): Conditionally displays `LiveCockpitMapScreen` when `activeGroupId != null`, or `RideStartView` when idle (`activeGroupId == null`).
  * `HomeTab.trips` (Tab 1): `TripHistoryScreen(embedded: true)`.
  * `HomeTab.alerts` (Tab 2): `AlertsScreen()`.
  * `HomeTab.profile` (Tab 3): `AccountScreen(embedded: true)`.
* **Dynamic Chrome Rules**:
  * When `activeGroupId != null` AND `_tab == HomeTab.ride`, the bottom `NavigationBar` is suppressed (`bottomNavigationBar: null`) to grant 100% of the display to the tactical map HUD.
  * System back gestures (`PopScope`) return non-ride tabs to `HomeTab.ride`. During an active ride on `HomeTab.ride`, back invokes `BackgroundService.minimizeApp()` to prevent accidental convoy disconnection.
* **Notification Callbacks (`_onRideNotifAction`)**:
  * Listens to `RideNotificationService.pendingUiAction` to handle background notification clicks:
    * `openFuel`: Selects `HomeTab.ride` and triggers `showEssentialsSheet(category: 'FUEL')`.
    * `navigateEmergency` / `assistAccept`: Launches `EmergencyGuidance` towards incident coordinates.
* **Service Dependencies**: `ConvoyService`, `RideNotificationService`, `RideEssentialsCoordinator`, `EmergencyGuidance`, `TimelineService`, `SafetyService`, `BackgroundService`.

### 2. `LiveCockpitMapScreen` Architectural Breakdown
* **Role**: Central high-density heads-up tactical map display during an active convoy.
* **Child Widget Hierarchy**:
  1. **Map Underlay**: `FlutterMap` with tile cache fallback, polyline corridor layer, rider markers with heading arrows, ghost-rider markers for offline riders, and hazard markers.
  2. **Top Tactical HUD Pills**:
     * `RoadHazardHudPill`: Spatial voice countdown & hazard warning pill (within 300m).
     * `SirenHudPill`: Pulsating alert and -20 dB intercom ducking indicator upon acoustic detection.
     * `BleRemoteHudPill`: Connection status and battery indicator for BLE handlebar remote.
     * `BiometricPulseHudPill`: Real-time smartwatch pulse telemetry and trauma classification.
     * `CockpitDualStateBanner`: Cellular vs offline corridor indicator.
  3. **Convoy Formation Widget**:
     * `RidersLadder`: 1D vertical ladder ("Bead Wire") displaying relative member spacing, Lead/Pack/Sweeper roles, and total convoy spread.
  4. **Right-Hand Action Stack (`CockpitActionStack`)**:
     * 48dp glove-friendly vertical column: Chat (`MessagesView`), Fuel (`FuelSheet`), Essentials (`EssentialsSheet`), Guardian (`GuardianSheet`), Settings (`GroupSettingsSheet`), Timeline (`LiveTimelineScreen`).
  5. **Draggable Bottom Dock (`RideSheet`)**:
     * Collapsed: Real-time speed (km/h), trip distance, elapsed time, and `MinimalHoldToTalkBar` (VOX/PTT).
