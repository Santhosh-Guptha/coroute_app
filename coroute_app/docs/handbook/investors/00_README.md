## Placeholders the owner must fill before sending

1. **The ask:** amount, instrument, use of funds, runway, milestones (one pager, memo §13, deck slide 13).
2. **Team:** founders and key hires (memo §12, deck slide 13). Name only people who have agreed.
3. **Contact details:** one pager, memo, press kit.
4. **Market sizes:** TAM / SAM / SOM inputs that need a sourced count of motorcycles in use and of group / touring riders (memo §5).
5. **Launch prices and access mode:** the code defaults (Small Group ₹49, Large Group ₹99 per 30 days; Paid mode) are configuration, not a decision (pricing doc §2, §3).
6. **Operator and partner pricing** (pricing doc §4, §5).
7. **Unit costs:** VMs, database, SMS per message, e-mail, payment fee (pricing doc §6.2, model Assumptions).
8. **Company documents** (diligence checklist §6).

## How the PDFs were made

Markdown and HTML rendered with Chromium (Playwright) in the brand palette (teal #2B7A8C, amber #D9822B, warm off-white) with Manrope. The build script is `_build/build_pdfs.py` in this folder; run `python3 docs/handbook/investors/_build/build_pdfs.py` after editing the Markdown (the one-pager PDF layout lives in that script, so update it too when `one_pager.md` changes). The spreadsheet is generated by `_build/build_model.py`; its formulas were checked by recalculating in LibreOffice: no errors with the blank inputs, and sensible results with throwaway test inputs that were not saved.

## Rules for editing this pack

- Never add traction, revenue, users, ratings, funding, valuations or market numbers without a source.
- Never copy anything from credentials documents, `.env` files or keys into these files.
- The Play app sells nothing: do not put prices in anything that could end up in the app or store listing.
