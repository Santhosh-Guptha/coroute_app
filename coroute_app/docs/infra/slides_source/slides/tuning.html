STEP 3 · SERVER TUNING

One script per role, read the dry run first

sudo ./deploy/host/apply.sh \
  --role realtime --peer-ip <vm2-private> \
  --dry-run

# then without --dry-run
# roles: realtime · web · dr · staging · worker

Safe to run again. It never restarts the gateway or deletes firewall rules.

  • Network and file limits sized for many open connections
  • Swap used only when needed; logs capped at 200 MB
  • Security updates automatic, never reboots
  • SSH keys only, no root, no passwords; fail2ban
  • Firewall: 80/443 public, internal ports only from the peer
  • Gateway restarts itself, with a memory limit

10 · Then restart vm2, check health, then vm1

Also set the load balancer health check to /api/health/live every 5 seconds, so a release drains riders to vm2 before vm1 restarts. The script refuses to disable SSH passwords if your user has no SSH key.
