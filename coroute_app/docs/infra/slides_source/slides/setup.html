SETUP FLOW

Seven steps, in this order

01

Prepare

Lock leaked accounts, fill the private inventory file, put keys in the Vault.

02

Back up first

Encrypted database backup and a test restore before touching anything.

03

Tune each server

host/apply.sh per role, dry run first. vm2 before vm1.

04

Staging on vm4

Deploy there, smoke test and load test.

05

Release to production

release.sh: vm4, then vm2, then vm1, with automatic rollback.

06

DR on vm3

Standby gateway, watchdog, offsite backups, weekly restore test.

07

vm5 when it arrives

Routing, map tiles, analytics, batch jobs.

08 · Stop at any failed health check

Every step has a check after it. If a health check fails, undo the last step and stop. Never restart vm1 and vm2 together.
