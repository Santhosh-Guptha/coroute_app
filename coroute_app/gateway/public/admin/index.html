2-step verification

Administrators sign in with a code from an authenticator app (Google Authenticator, Microsoft Authenticator, 1Password, Aegis…). Scan this code, or type the key, then enter the 6-digit code it shows.

Key:

Save your recovery codes

Each code signs you in once if you lose your phone. Keep them somewhere safe, offline. They are not shown again.
