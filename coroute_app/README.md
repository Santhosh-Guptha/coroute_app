# CoRoute

Ride together, stay safe — a free convoy app for group riders: live map, rider telemetry,
SOS, planned stops, quick-status cards and a real-time voice intercom (group or 1:1).

* `lib/` — Flutter app
* `gateway/` — Node.js real-time gateway + Oracle Autonomous DB persistence
* `PRODUCTION_PLAN.md` — architecture, audit, rollout plan
* `gateway/deploy/RUNBOOK.md` — zero-cost deployment on OCI Always Free
